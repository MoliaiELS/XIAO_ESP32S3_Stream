# 新 IMU UART 独立测试

依据用户提供的《通信协议.xlsx》和模块参数截图实现。适用于帧头 `7E 23` 的新模块，不适用于旧 DM-IMU。驱动仅依赖 ESP32 Arduino 自带库。

## 接线

断电接线；按截图说明，该模块允许 3.3V 或 5V 供电，首次测试采用 3.3V。

| 新 IMU | XIAO ESP32S3 | 说明 |
|---|---|---|
| 电源口（截图标为 5V） | 3V3 / 3.3V-OUT | 按截图的“工作电压 5V 或 3.3V”使用；不要接 GPIO |
| GND | GND | 共地 |
| TX | D7 / GPIO44 | 模块发送，ESP32 接收 |
| RX | 默认不接 | 自动上报无需发送命令 |
| SDA / SCL | 不接 | 本例使用 UART |

不使用之前的 TTL485/MAX13487E 转换板。截图没有明确给出 UART 电平规格；使用前确认 TX 是 3.3V 逻辑，尤其不要因模块允许 5V 供电就把 5V TX 信号直接接到 ESP32。若实测/厂家确认 TX 为 5V，需降到 3.3V 后再接 D7。

需要查询版本时，加接 **模块 RX ← XIAO D6/GPIO43**，并把 `imu.imu_init(44,-1,115200)` 改成 `imu.imu_init(44,43,115200)`。数字 44、43 是 GPIO 编号。D4/D5 留给马达 I2C。

## 使用

1. Arduino IDE 打开本目录的 `imu.ino`，保持 `imu.hpp` 与其同目录。
2. 开发板选择 XIAO_ESP32S3；USB CDC On Boot 设为 Enabled，选择正确串口并上传。
3. 打开 115200 波特率串口监视器，模块上电后等待约 5 秒。
4. 转动模块，观察 `Q(wxyz)`、`RPY rad`、`deg`。默认每 100ms 打印；接收持续运行，模块默认约 25Hz。
5. 发 `d` 查看诊断，`p` 暂停/恢复样本打印（仍接收），`v` 查询版本（需要双向接线）。

`bytes=0`：没有收到 UART 字节，检查供电、共地、TX 到 D7 和启动等待。`bytes` 增长但 `frames=0`：检查协议、115200 8N1、电平、接触和校验错误计数。`frames` 增长但 q/rpy 某项始终为零：模块未输出该类帧，应检查模块输出设置。数据超过 500ms 不再作为实时值打印，旧值仍可从对象读取，使用前应检查 fresh 方法。

## 接口与协议

实例用法：`HardwareSerial uart(1); Imu sensor(uart);`，在 setup 调用 `sensor.imu_init(44,-1)`，loop 持续调用 `sensor.imu_update()`。读取 `sensor.quaternion`、`sensor.rpy_rad`、`sensor.rpy_degrees()`；用 `quaternion_fresh(millis())` 和 `rpy_fresh(millis())` 分别判断有效性。两类数据独立到达，不能视为同一时刻的原子快照。

可创建多个 Imu 实例，但每个物理 UART 模块需独立 HardwareSerial 控制器及 RX/TX 引脚；不能将多个 TX 并接到一个 RX，也不能让两个实例重新配置同一 UART。

帧：`7E 23 总长度 功能码 数据 累加和低8位`。总长度包含校验字节；没有帧尾。浮点数为 little-endian float32。

- `0x16`：21 字节，四元数 w/x/y/z。
- `0x26`：17 字节，roll/pitch/yaw，原始单位**弧度**，显示时另转角度。
- `0x01`：8 字节，版本号。
- 加速度/角速度/磁场、气压等其他有效帧校验并计数，本例不解码。

表格中欧拉角行标题误写“返回四元数”，实现以功能码、字段及单位说明为准。解析器处理分包、连续帧、校验失败及重新同步，拒绝非有限浮点数和明显无效四元数（模平方不在 0.5～1.5）。不自动校准、不改输出频率、不恢复出厂设置。
