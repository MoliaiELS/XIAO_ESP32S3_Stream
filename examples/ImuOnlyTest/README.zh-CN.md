# DM-IMU-L1 独立测试 + 照片中的 TTL485-V2.0

打开本目录 **ImuOnlyTest.ino**，保留同目录 `DmImuParser.h`。无马达、摄像头、Wi-Fi 和额外 Arduino 库；只接收 IMU 已解算的四元数及 RPY。程序不会通过 RS485 发送配置指令。

## 这块转换板能不能用

用户补充芯片标记为 `MAX1348 7ECSA +138`，对应 **MAX13487E** 系列。它是 **5V 供电、自动方向、最高 500kbps 的 RS485 收发器**，可用于本例 115200 通信。后缀/批次不改变按 5V 芯片处理的结论；照片无法确认模块有无额外电平转换，因此接收输出按 5V 域处理。

**能用，但不能按 3.3V 模块直接接线。模块 VCC 用 5V，TXD 经 5V→3.3V 电平转换后接 ESP32。** 不给 MAX13487E 降到 3.3V 供电来凑电平；这不是其规定的工作供电。

背面箭头明确：**模块 TXD 是输出 → 单片机 RXD；模块 RXD 是输入 ← 单片机 TXD**。

## 接线：MAX13487E 版本

先断电。采用一块明确支持 UART 推挽信号的 5V→3.3V 电平转换模块。例如使用 **SN74LVC1G125 转接板**：芯片 VCC 接 3.3V，输入允许接收 5V，输出为 3.3V 域。不要只凭“电平转换”名称随意替代，须核对其型号、方向和接法。

| TTL485-V2.0 | 接哪里 |
| --- | --- |
| TTL 侧 VCC | 稳定 **5V** 电源 |
| TTL 侧 GND | XIAO GND、IMU GND、电源负端共地 |
| TTL 侧 **TXD** | 电平转换器 5V 信号输入；转换器输出 → XIAO **D7/GPIO44** |
| TTL 侧 **RXD** | 通过 **10kΩ 上拉到模块 VCC（5V）**，保持空闲高 |
| 螺丝端子 **D+/A** | IMU **485 A** |
| 螺丝端子 **D−/B** | IMU **485 B** |
| 螺丝端子 GND | IMU GND |

本例只接收，XIAO D6/GPIO43 **不接**。RXD 上拉接模块自身 5V，不接 ESP32；如果厂家明确内置输入上拉，可按其说明省略。不要把 RXD 接 GND，它不是 DE 引脚。

以 SN74LVC1G125 为例，按器件/转接板的**信号名**接（引脚编号依封装核对）：

| SN74LVC1G125 | 连接 |
| --- | --- |
| VCC | XIAO 3V3 |
| GND | 共地 |
| /OE | GND，使能输出 |
| A 输入 | TTL485 模块 TXD |
| Y 输出 | XIAO D7 / GPIO44 |
| 去耦 | VCC 与 GND 附近 0.1µF；转接板若已有则使用板上电容 |

IMU 电源正端接稳定 **5V**，负端接共地。DM-IMU-L1 允许 5–28V，不能由 XIAO 3V3 供电。IMU 与转换板可共用足额的稳压 5V，XIAO 由自身 USB 供电；外部 5V **不接回 XIAO 5V**。先用 IMU 自身 USB 配置，配置后拔下该 USB，再接外部供电运行，避免未确认隔离时双路供电。

```text
DM-IMU-L1          TTL485-V2.0           LVC1G125              XIAO
485 A ─────────── D+/A
485 B ─────────── D-/B
GND ───────────── GND ────────────────── GND ──────────────── GND
                   TXD ──────────────── A → Y ────────────── D7/RX
                   RXD ──10kΩ──5V       /OE──GND
电源正端──5V       VCC──5V               VCC───────────────── 3V3
```

没有电平转换器时先不要直连 TXD。也可改用明确支持 3.3V 供电及输出的 RS485 模块，程序不变。不能用万用表对持续数据测出的平均电压证明 5V 输出可直连。

照片上的 `120_S` 是终端电阻选择焊盘，背面画了 A—开关—120Ω—B。按模块说明及已有终端数量决定是否闭合；不要重复并接。点到点总线按两端匹配处理，A/B 使用双绞线。IMU 接 485 A/B，不是 CAN H/L，线束颜色和针序以实际说明为准。

## 第一步：通过 IMU 自身 USB 配置

打开工作区 `dm-imu/上位机/DM-IMU-Upper v1.0.0.2.zip` 内上位机，选择 IMU 的 COM 口，进入设置模式：

1. 输出接口：**485**。
2. 模式：**主动输出**，不是应答模式/Modbus。
3. 波特率：**115200**，8N1。
4. 频率：**100Hz** / 发送间隔 **10ms**。
5. 从机 ID / CAN_ID：**1**。
6. 开启 **欧拉角和四元数**。加速度、角速度可保留，解析器支持混合数据流。
7. **保存参数**，返回正常模式。重启确认保存，然后按上节切换运行供电。

115200 足以发送 100Hz 的四类数据（8000 字节/秒），不要同时设为四类 1000Hz。串口监视器的 115200 是 XIAO→电脑，IMU_BAUD 是 IMU→XIAO，两者是不同链路。若你使用另一 IMU 波特率/ID，需要修改 .ino 顶部 IMU_BAUD/IMU_ID 并使 IMU 配置一致。

## 第二步：上传独立程序

1. Arduino IDE 打开 **ImuOnlyTest.ino**。
2. 选择 **XIAO_ESP32S3**、XIAO 的 COM 口、**USB CDC On Boot=Enabled**。
3. 编译上传，打开串口监视器，**115200**。
4. 无需发送启动命令，收到真实数据后会自动显示四元数和 RPY。

输出格式：

```text
IMU ms=... q_wxyz=w,x,y,z rpy_deg=roll,pitch,yaw age_ms=四元数年龄,欧拉角年龄
```

四元数顺序 **w,x,y,z**，RPY 单位为 **度**，直接读取 IMU 两种数据帧。打印为 10Hz，接收仍持续处理 100Hz。两个帧的 age_ms 独立，协议没有采样时间戳，不保证它们严格同步。

任一种姿态超过 250ms 未更新，就停止输出组合姿态，避免把旧值当新值。六轴 IMU 没有绝对磁航向，Yaw 可能漂移。静置校准时关闭马达，按 IMU 坐标箭头判断绕轴方向。

## 串口和 LED 排查

发送单字符（有无换行均可）：

- `p`：状态统计、最近合法帧的 ID/寄存器、姿态年龄。
- `x`：最近收到的 32 字节 HEX，仅为连续流末尾片段，不一定从帧头开始。
- `o`：开启/关闭姿态打印；接收和每 3 秒状态打印继续。
- `h`：帮助。

板载 USER_LED（GPIO21，低电平亮；不是充电灯）每 3 秒重复：

| 每组次数 | 含义 |
| --- | --- |
| 1 | RPY 和四元数均为新数据 |
| 2 | 没有收到字节，或超过 500ms 无字节 |
| 3 | 收到字节，但没有新鲜的匹配 ID 姿态数据 |
| 4 | 只有 RPY 或四元数其中一种新鲜 |

转换板的电源灯、TXD/RXD 灯由板上电路决定，不等于 CRC 正确；LED 脉冲频繁时也可能肉眼看成常亮。

| 状态 | 先检查 |
| --- | --- |
| rx_bytes=0 | IMU 已保存的485主动输出配置、供电、模块 TXD→D7、RXD 空闲高 |
| all_crc_valid=0，字节增长 | 波特率、A/B 极性、共地、电平、是否错误选择 CAN/应答协议 |
| other_id 增长 | last_id 与 IMU_ID 不一致；只对 CRC 正确的帧报告 ID |
| matched 增长但仅一种 seen/fresh | 是否同时开启欧拉角和四元数输出 |
| crc_errors 持续增长 | 信号完整性、终端、松动、供电、电平；不关闭 CRC 来掩盖 |
| invalid_values 增长 | CRC 正确但浮点非有限/四元数模长明显异常，核对固件和协议版本 |

接好后若没有姿态，发 `p` 和 `x`，提供两段输出以及每组闪灯次数。

## 验证与依据

解析器沿用已测试的 DM-IMU 流式解析，增加 CRC 正确帧总数、其他 ID 计数和最近 ID/寄存器诊断。支持 19/23 字节帧、小端浮点、CRC16-CCITT-FALSE、错帧恢复、半帧超时。不生成模拟姿态。

依据：工作区 DM-IMU-L1 使用说明书 V1.2（供电/协议/CRC），厂商 ROS1 示例（角度单位和小端 CRC），本次用户提供的 TTL485-V2.0 正反面丝印（接口方向）。用户随后补充 MAX13487E 芯片标记；据此采用 5V 供电加接收电平转换方案，尚未进行硬件验证。

芯片对照：[MAX3485 官方资料](https://www.analog.com/en/products/max3485.html)、[MAX13487E 官方资料](https://www.analog.com/en/products/max13487e.html)。

电平转换依据：[SN74LVC1G125 官方资料](https://www.ti.com/product/SN74LVC1G125)。
